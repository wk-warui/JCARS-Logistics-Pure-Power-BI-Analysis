# JCARS Logistics Power BI Analysis

This project analyses JCARS Logistics sales and operational data using **Microsoft Power BI**.

## Project Overview
The project involved cleaning a raw vehicle sales dataset, standardizing currencies and data formats, creating DAX measures, and developing an interactive Power BI dashboard to analyse sales, revenue, costs, profitability, branches, and vehicle types.

## Dataset
- Original records: **276**
- Final cleaned records: **255**
- Original columns: **32**
- Final columns: **34**
- Reporting currency: **KES**

## Work Completed
- Data quality audit and cleaning using Power Query
- Duplicate and inconsistent value handling
- Currency standardization to KES
- Data validation
- Date table and data modelling
- DAX measures for revenue, costs, profit, margin, units, and orders
- Interactive Power BI dashboard
- Business insights and recommendations

## Key Result
The analysis recorded approximately **KSh1.24 billion in revenue**, with **415 units sold across 255 orders**. The calculated gross profit was approximately **-KSh103.27 million**, highlighting areas requiring further investigation.
